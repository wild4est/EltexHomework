### Общее
Сборка сервера и клиента
```bash
make all
```

Очистка сервера и клиента
```bash
make clean_all
```

Во время запуска сервера ему необходио задать порт и сетевой адрес
```bash
sudo ./server_main 1234 0.0.0.0
```

Во время запуска клиента ему необходимо задать порт и сетевой адрес, а так же указать порт и адрес сервера
```bash
# ./client_main <порт клиента> <порт севера> <сетевой адрес клиента> <сетевой адрес севера>
sudo ./client_main 1234 1234 0.0.0.0 0.0.0.0
```

## Сервер
Сборка сервера
```bash
make compile_server
```

Очистка сервера
```bash
make clean_server
```

## Клиент
Сборка клиента
```bash
make compile_client
```

Очистка клиента
```bash
make clean_client
```
